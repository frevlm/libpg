# 用户面按 v2 整体重写，只保证使用方迁移后的行为不变

libpg 自己的 API 不受兼容性约束，按 v2 整体重写，而不是在 v1 上打补丁。
必须保持不变的是 revlm、HHHOJ 迁移之后的**行为**：`f(Db&, ...)` 这类非模板函数签名、READ COMMITTED 事务、
迁移的一个事务语义、advisory lock 的 key。本目录里 0003 以后的决定描述的是 v2。

## Consequences

- 池和写回缓存都是使用方持有的对象，没有全局池，也没有退出前必须调用的 `pg::shutdown()`。
- 使用方迁移时有几处行为变化需要显式决定，不能顺手改掉，例如 revlm 拼 LIKE 时没有转义 `%` 和 `_`。
